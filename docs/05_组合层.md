## 加权方法

| 方法 | 优点 | 缺点 |
|---|---|---|
| 等权 | 简单稳健 | 没考虑因子质量 |
| ICIR 加权 | 按预测力 | 对历史敏感 |
| **正则化 ML（enet/ridge）** | 能处理共线性 | 需样本量 |
| 最大化 IC | 理论最优 | **严重过拟合** |

## 🔴 纪律 B36：因子数量与加权方法必须匹配

**实测（同一批因子、不同加权方法，结论相反）**

| 加权方法 | 精选库（18）| 全库（163）|
|---|---|---|
| **线性 ICIR 加权** | **+0.94** ✅ | **−0.36** ❌ |
| **正则化 ML（enet）** | +0.82 | **+0.97~1.14** ✅ |

> **线性加权对噪声敏感必须精选；正则化 ML 能自动降权噪声，全库更好。**

## 组合优化（带约束）

```python
import numpy as np
from scipy.optimize import minimize

def optimize(alpha, industry, max_ind=0.05, max_stock=0.02):
    n = len(alpha)
    def obj(w):
        return -(alpha @ w) + 0.5 * 10 * (w @ w)
    cons = [
        {"type": "eq", "fun": lambda w: w.sum() - 1},
        {"type": "ineq", "fun": lambda w: max_ind -
         np.abs(__import__("pandas").Series(w)
                .groupby(industry).sum()).max()},
    ]
    res = minimize(obj, np.ones(n)/n, bounds=[(0, max_stock)]*n,
                   constraints=cons, method="SLSQP")
    return res.x
```

## 🔴 纪律 B48：「组合稀释」的机制是「相关性上升」

**实测（固定 V8 权重 vs 重新风险平价）**

| 配置 | 股票权重 | 股商相关 | 股债相关 | 组合夏普 | **固定权重夏普** |
|---|---|---|---|---|---|
| V8 | 0.156 | **−0.158** | **−0.085** | **2.253** | 2.253 |
| V11（+GP）| 0.202 | **+0.073** | **+0.085** | 1.750 | **1.853** |

**→ 权重效应只占 20~30%；真正机制是「相关性上升」→ 分散红利消失。**

**优化方向应从「提高单线 IR」转向「降低线间相关性」。**
