## 压力测试（7 类）

| 场景 | 测什么 |
|---|---|
| 相关性骤升（0.95）| 分散失效 |
| 单线失效（−20%）| 抗单点故障 |
| 流动性枯竭（成交额 −80%）| 容量 |
| 成本翻倍 | 成本敏感性 |
| 最大回撤期重现 | 尾部 |
| 蒙特卡洛（12 个月）| 分布 |
| 极端波动（3 倍）| 杠杆风险 |

**🔴 纪律 B19**：**场景模拟必须保留一阶矩**（用 `mu + sd*x` 而非仅 `sd*x`）。
本项目曾因用 `standard_normal() @ L.T`（零均值）得到「相关性上升是致命的（−0.196）」的错误结论。

**本项目实测**：
- 相关性 0.95 → 夏普仍 **+1.777**
- MC 12 个月 → 99% 分位回撤 **−2.6%**，P(夏普<0) = **1.4%**
