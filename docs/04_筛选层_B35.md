# 04 筛选层 —— B35 四步法（**本项目核心方法论**）

## 为什么需要四步

**只用「全样本夏普」筛因子 = 必然过拟合。**

本项目实测：848 个因子组合中，「训练窗最优」的组合在全样本排第 712 名，但测试窗却是第 1 名 → **训练窗表现完全无预测力**。

## 四步法

```
① 全样本夏普 / ICIR          → 粗筛
② 多子区间正比例 ≥ 80%       → ★ 核心
   且 最小区间 > 0
③ 与已有因子相关性 < 0.7     → 去冗余
④ 组合增量 > 0（每个子区间） → 最终确认
```

## 代码

```python
from src.screening import b35_screen, step3_correlation, step4_combo_increment

# 第 ①② 步
res = b35_screen(ic)
print(res)   # {ICIR, 正比例, 最小区间, 中位, 通过}

# 第 ③ 步
max_c, which, ok = step3_correlation(ic_new, ic_zoo)

# 第 ④ 步
inc = step4_combo_increment(base_stream, new_stream)
```

## ⭐ 实证支撑（最有力的论据）

**同一批 21 个"实物面"因子**（仓单/LME 库存）：

| 因子 | 全样本夏普 | 正比例 | 最小区间 | 判定 |
|---|---|---|---|---|
| **`RECEIPT_CHG_5`** | **+0.830（最高）** | **60%** | **−0.625** | **拒绝** ❌ |
| `RECEIPT_YOY` | +0.744 | **100%** | **+0.035** | **采纳** ✅ |

**→ 全样本夏普最高的因子反而不能要。**

## 🔴 坑：训练窗选参数 = 过拟合

**实测（期货单品种趋势，10,000 元本金）**

| 品种 | 训练夏普 | 测试结果 |
|---|---|---|
| C 玉米 | **+1.943（最高）** | **穿仓** |
| TA PTA | +1.081 | **穿仓** |
| MA 甲醇 | **+0.621（最差）** | **盈利 +4.69%** |

**8 个两品种组合：训练夏普 vs 测试夏普相关 = −0.597**

**→ 训练窗表现不仅没预测力，甚至反向指示。**
