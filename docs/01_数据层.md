# 01 数据层 —— 一切的地基

## 需要哪些数据

| 类别 | 内容 | 用途 |
|---|---|---|
| 行情 | 日线 OHLCV + 复权因子 | 价量因子、收益 |
| 基本面 | 财报（营收/利润/ROE/负债）| 价值/质量 |
| 市值 | 流通市值、总市值 | **中性化必需** |
| 行业 | 申万/中信分类 | **中性化必需** |
| 指数成分 | 中证1000 历史成分 | **股票池** |
| 交易日历 | 交易日/停牌/涨跌停 | 可交易性 |

**免费数据源**：`akshare`（推荐）、`baostock`

## 🔴 坑 #1：股票池必须与策略池一致

**症状**：因子在全市场 IC 很高，但在策略池里失效。

**原因**：用 5,481 只股票算 IC，但策略只在中证1000 的 1,626 只里选股 → 样本不一致。

**正确做法**：
```python
from src.universe import build_universe
uni = build_universe(rebal_dates, codes, mask, float_mv)
# 只在 uni=True 的股票上算 IC
```

## 🔴 坑 #2：停牌 / 涨跌停 / 复权

| 问题 | 后果 | 处理 |
|---|---|---|
| 停牌当 0 收益 | 低估波动、虚假低换手 | 从可交易池剔除 |
| 涨跌停当可交易 | 虚假成交 | 涨跌停日排除买卖 |
| 前复权/后复权混用 | 收益率错乱 | 全流程统一 |

## 🔴 坑 #3：前视偏差

| 类型 | 例子 | 后果 |
|---|---|---|
| 财务数据 | 用 Q1 财报在 3 月选股 | **严重高估** |
| 因子筛选 | 用全样本 IC 挑因子 | 高估（本项目实测虚高 16 倍）|
| 参数选择 | 用全样本最优参数 | 高估 |
| 指数成分 | 用当前成分回测历史 | 幸存者偏差 |

**正确做法**：财务按**公告日**对齐；筛选/调参**只用训练窗**；成分用**历史快照**。

## 交易日历对齐（关键）

**🔴 坑**：用「并集日历」构造调仓网格，会导致错位。

**正确做法**：用**主数据源的日历**，不要用并集。

```python
# ❌ 错误
dates = sorted(set(all_dates_from_all_sources))
# ✅ 正确
dates = sorted(price_df.index.unique())   # 只用主源
```
