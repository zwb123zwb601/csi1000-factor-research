# 02 因子层 —— 构造与处理

## 因子分类

| 大类 | 代表因子 | 数据 |
|---|---|---|
| 价量 | 动量、反转、波动、换手、Amihud | 日线 |
| 价值 | BP、EP、SP、股息率 | 财报 |
| 质量 | ROE、毛利率、资产负债率、应计 | 财报 |
| 成长 | 营收增速、利润增速 | 财报 |

## 处理三步（顺序不能错）

```
原始值 → ① 去极值(MAD) → ② 标准化(rank) → ③ 中性化(市值+行业) → 可用因子
```

### ① 去极值（MAD）

```python
med = x.median()
mad = (x - med).abs().median()
x = x.clip(med - 3*1.4826*mad, med + 3*1.4826*mad)
```

### ② 标准化（rank）

比 z-score 稳健，不受分布影响。

### ③ 中性化（**最关键**）

**为什么必须做**：
- 小市值股天然波动大、换手高 → 任何因子都"看起来"在小市值上有效
- 银行股 PB 天然低 → BP 因子"看起来"在银行上有超额

**做法**：对 `[log(市值), 行业哑变量]` 回归取残差

```python
from src.factors import neutralize
factor_neutral = neutralize(factor, log_mv, industry)
```
