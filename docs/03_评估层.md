# 03 评估层 —— 一个因子好不好

## 三个核心指标

| 指标 | 经验值 | 说明 |
|---|---|---|
| **ICIR** | >0.5 可用，>0.8 优秀 | **稳定性比 IC 重要** |
| 分层单调性 | ≥0.6 | IC 高但不单调 = 只在极端值有效 |
| 因子相关性 | <0.7 | 去冗余 |

## IC / ICIR

```python
from src.evaluation import ic_series, ic_stats

ic = ic_series(factor, fwd_ret, valid)      # 逐期 RankIC
stats = ic_stats(ic)                         # IC / ICIR / 期数
```

**经验值（A 股月频）**

| ICIR | 评价 |
|---|---|
| < 0.3 | 弱，基本没用 |
| 0.3 ~ 0.5 | 可用（配合其他因子）|
| 0.5 ~ 0.8 | 好 |
| > 0.8 | 优秀（但要警惕前视偏差）|

## 分层回测

```python
from src.evaluation import layered_returns, monotonicity

layered = layered_returns(factor, fwd_ret, valid, n_layer=10)
mono = monotonicity(layered)           # 单调性 (应 > 0.6)
```

**看什么**：
- **单调性**：第 1 层到第 10 层收益是否单调
- **多空收益**：第 10 层减第 1 层
- **分层可解释**：每层股票数是否够（本项目要求「各期最大同值块占比 ≤20%」）

## 换手率

| 换手 | 含义 | 成本影响 |
|---|---|---|
| < 20%/期 | 低 | 好 |
| 20~50%/期 | 中等 | 可接受 |
| **> 50%/期** | **高** | **必须做成本敏感性（B39）** |

**本项目实测**：GP 因子组合换手 75%/期 → 10bp 成本下夏普从 1.570 降到 **0.615**（−63%）。

