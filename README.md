# CSI 1000 Factor Research

A股中证1000多因子选股 —— 完整研究流程与可复用代码。

## 这是什么

一套经过实盘级别验证的 A 股多因子选股流水线，包含：
- **7 层完整流程**：数据 → 因子 → 评估 → 筛选 → 组合 → 验证 → 实盘
- **B35 四步筛选法**：本项目总结的因子筛选方法论
- **68 条量化研究纪律**：每条都标注来源与偏差量
- **8 个真实踩坑案例**：展示如何发现自己的错误
- **可运行代码**：股票池构建、因子处理、IC 评估、B35 筛选、组合优化

## 核心结论（先看这个）

1. **训练窗表现与测试窗表现可以是负相关的**（实测 −0.597）
2. **单线 IR 提高 ≠ 组合夏普提高**（7 次实验证实，机制是「相关性上升」）
3. **「正交性 ≠ 组合改善」**（最正交的因子组合层面反而一致为负）
4. **因子数量要与加权方法匹配**（线性加权需精选，正则化 ML 用全库）
5. **每个结论都要独立复算**（8 次自我推翻全靠它）
